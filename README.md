# 2D Rigid Body Physics — CCD и Multi-rate симуляция

Практическая работа № 3 по дисциплине «Моделирование физических процессов».

Проект представляет собой двумерную физическую симуляцию круговых тел с использованием C++ и библиотеки SFML. Реализованы дискретное и непрерывное обнаружение столкновений, а также обновление групп объектов с разной частотой.

## Возможности

- **DCD (Discrete Collision Detection)** — дискретное обнаружение столкновений после перемещения объекта за физический шаг.
- **CCD (Continuous Collision Detection)** — непрерывное обнаружение столкновений с вычислением времени контакта внутри временного шага.
- **Multi-rate simulation** — обновление разных групп объектов с разной частотой:
  - Обычная группа: 20 шаров, 60 Гц.
  - Быстрая группа: 5 шаров, 240 Гц.
- Моделирование гравитации и столкновений шаров между собой и со стенками контейнеров.
- Демонстрация эффекта туннелирования при высокой скорости движения объекта.
- Измерение времени выполнения физических обновлений с помощью `std::chrono`.

## Используемые технологии

- C++
- SFML (Simple and Fast Multimedia Library)
- Visual Studio
- CMake (если используется в конфигурации проекта)

## Запуск проекта

Для запуска проекта:

1. Скачайте репозиторий с GitHub, нажав **Code → Download ZIP**.
2. Распакуйте скачанный архив в удобную папку.
3. Откройте файл решения проекта `.sln` в Microsoft Visual Studio.
4. Дождитесь загрузки проекта.
5. Выберите конфигурацию **Release** или **Debug**.
6. Нажмите **Ctrl + F5** для запуска программы без отладчика.

После успешной сборки откроется окно симуляции.

**Примечание:** для сборки и запуска необходима установленная библиотека SFML и корректно настроенные пути к её заголовочным файлам, библиотекам и динамическим DLL-файлам. Если зависимости уже настроены в проекте, дополнительных действий не требуется.

## Управление

| Клавиша | Действие |
|---|---|
| `1` | Включение режима DCD |
| `2` | Включение режима CCD |
| `B` | Повторное создание наборов шаров |
| `Esc` | Выход из приложения |

## Параметры симуляции

| Параметр | Значение |
|---|---:|
| Размер окна | 1000 × 700 px |
| Ускорение свободного падения | 900 px/с² |
| Начальная скорость снаряда | 2000 px/с |
| Толщина препятствия | 10 px |
| Радиус снаряда | 5 px |
| Обычная частота обновления | 60 Гц |
| Быстрая частота обновления | 240 Гц |
| Количество обычных шаров | 20 |
| Количество быстрых шаров | 5 |

## Структура проекта

- `main.cpp` — главное окно приложения, основной цикл симуляции, обработка событий и алгоритмы DCD/CCD.
- `ball.cpp` — создание шаров и контейнеров, обновление движения и обработка столкновений.
- `ball.h` — объявления структур и функций для работы с шарами и контейнерами.

## Результаты работы

В рамках проекта исследуются следующие явления:

- Туннелирование быстрого объекта при дискретной проверке столкновений.
- Обнаружение столкновения с помощью CCD.
- Влияние увеличения частоты обновления с 60 до 240 Гц на корректность обнаружения столкновений.
- Различия в вычислительной нагрузке для групп объектов с разной частотой обновления.
